# Dentigo — Dental Case Management System

Dentigo is a dental case management project focused on managing the journey of a dental case between the doctor and the laboratory.

## Project documentation

The source documents are being organized into the following folders:

- `Documentation/` — MVP scope and Software Requirements Specification (SRS).
- `Database-Design/` — database design and data model.
- `Diagrams/` — system analysis and UML diagrams.

## Source of truth

Use the supplied project documents as the source of truth. Do not infer undocumented requirements or backend functionality; record unresolved decisions instead of assuming answers.
